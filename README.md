# Thrifters

**Thrifters** is a web-based project developed as part of the **Web
Application and Databases** course.\
The project demonstrates the design and development of a modern web
application, focusing on database integration, user interaction, and
practical full-stack development concepts.

------------------------------------------------------------------------

## 📘 Course Information

This repository contains coursework created for the **Web Application
and Databases** module.\
It showcases core skills such as:

-   Building dynamic web applications
-   Database design and integration
-   Backend and frontend development
-   Version control using GitHub

## ⚙️ Installation & Setup

1.  Clone the repository: git clone
    https://github.com/Fabasshirlab/Thrifters.git

2.  Navigate into the project folder: cd Thrifters

3.  Install dependencies (if applicable): npm install

4.  Run the development server: npm start
